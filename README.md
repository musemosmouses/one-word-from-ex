One word, the word an ex would use to describe you: he was almost the one — almost grown up, almost ready, almost good enough. An adverb doing the job of a confession: a whole almost-relationship in a single word. It stings because it is true, not because it is mean, and everyone has lived it.

> Almost

## Run

```sh
node main.ts
```

This writes the entry to `out/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The program is deterministic: no network, no clock, no randomness. The entry is 6 characters, within the 1–24 character cap, exactly one word.
